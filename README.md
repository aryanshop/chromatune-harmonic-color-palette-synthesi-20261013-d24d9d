# ChromaTune: Harmonic Color Palette Synthesizer

ChromaTune is an interactive web-based color palette generator that translates musical chord and scale intervals into mathematically harmonious color palettes.

## Purpose & Features
- **Music Theory Harmony Engine**: Generate palettes using intervals like Major chords, Minor chords, Pentatonic scales, Dominant 7ths, and Diminished intervals mapped onto the color wheel.
- **Interactive Swatches**: Click any color swatch to hear a synthesized musical tone corresponding to its interval position.
- **Swatch Locking**: Lock individual colors you like while randomizing or changing harmony modes for the rest of the palette.
- **Accessibility Analyzer**: Real-time WCAG contrast ratio calculation against black and white text.
- **Flexible Export**: Instantly export your palette as CSS variables, JSON, or Tailwind config objects.

## Local Run Instructions
1. Download or clone all project files (`index.html`, `style.css`, `script.js`, `README.md`) into a single folder.
2. Open `index.html` directly in any modern web browser.

*Note: This is a fully static client-side web project. No external server, build tools, or network connections are required.*
